# WorkSphere – Multi-Tenant HR Management SaaS

WorkSphere is a multi-tenant HR Management SaaS platform where multiple companies can register and manage their employees, attendance, and leave requests with strict company-level data isolation.

## Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios, React Router
- **Backend:** Node.js, Express.js, Prisma ORM
- **Database:** PostgreSQL
- **Security:** JWT, bcrypt, Zod, Role-Based Access Control (RBAC)
- **DevOps & Cloud:** Docker, Docker Compose, Nginx, GitHub Actions, AWS (EC2, IAM, S3, CloudWatch)
